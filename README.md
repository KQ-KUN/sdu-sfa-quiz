# 山东大学学生科幻协会 · 星际入会测试

[打开游戏网站](https://kq-kun.github.io/sdu-sfa-quiz/)

明亮色系、适配平板的科幻招新小游戏。简单与困难各 30 题，每轮随机抽取 10 题，同一作品最多出现 2 题，四个选项随机排列。答题后显示解释，结束后显示答对题数、招新群二维码与 QQ 群号 698414186。

所有图片和题库均内嵌在页面中，运行时没有第三方脚本、字体或图片依赖，不收集参与者信息。困难题中的关键情节标有“剧情题”。现场设置可更换群二维码，并导出包含更新后的二维码的单文件 HTML。

## 使用

平板在浏览器中访问 GitHub Pages 网站。网站首次加载需要网络；页面加载完成后，当前页面答题无需额外网络请求。不要将离线答题等同于离线重新打开网站。

也可下载 `docs/index.html`，用支持本地 HTML 脚本的浏览器打开。iPad 的文件预览通常不支持完整互动，优先使用网站地址。

## 构建与验证

需要 Node.js，无需安装 npm 依赖。

```sh
node build.mjs
node tests/core.cjs
```

- `src/questions.json`：两档题库、四个选项、答案、解析与来源。
- `src/template.html`：页面布局和交互。
- `src/quiz-core.js`：抽题与选项随机逻辑。
- `assets/`：社团提供的原始会徽、社娘表情图与群二维码。
- `docs/index.html`：生成的单文件网页，也是 GitHub Pages 发布入口。
- `题库与参考来源.md`：可供人工审阅的完整题库。

Pages 从 `main` 分支的 `/docs` 文件夹发布。修改源码后先构建、验证，再提交生成的页面。

图片未授予第三方再使用许可；作品名称仅用于科幻知识问答。二维码更新仅保存在当前浏览器，网站内更换二维码不会自动更新所有访客看到的版本。若需全站替换，请更新 `assets/recruitment-qr.jpg` 并重新构建发布。
